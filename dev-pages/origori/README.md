# オリゴリと、つくる。— ローカルデザイン案

現在のmorimizu worksの情報とページ構成を使い、オリゴリがいる少しゆるい雰囲気を検討するためのプレビューです。

```sh
npm run dev:origori
# http://127.0.0.1:3005/
npm run build:origori
node dev-pages/origori/verify.mjs
node dev-pages/origori/verify-motion.mjs
node dev-pages/origori/verify-walking.mjs
node dev-pages/origori/verify-mascots.mjs
```

ページ上部で「オリゴリ案」と「現行デザイン」を切り替えられます。直接の比較URLは `http://127.0.0.1:3005/?view=current`。
「素材一覧」から `http://127.0.0.1:3005/origori-assets` を開くと、7種類の基本ポーズを4つの背景・24/48/96pxで比較し、SVG・透過PNG・3種類のGIFをダウンロードできます。

## デザイン

- 紙色の背景、青緑の文字、淡い色のカード、少し丸いボタン。
- トップの大きなオリゴリと、各入口・技術ノート・プロフィール・フッターの小さなポーズ。
- オリゴリ本体を押すと、たつ→すわる→ひらめき→ひとやすみの順に変形。1秒未満の間隔で5回続けて押すと、くしゃくしゃになり、2.2秒後に復元します。復元を待たずにもう一度押しても戻せます。
- 「オリゴリと、ひと息」で休憩ポーズを直接切り替えられます。
- トップのProjects / Notes / Aboutのオリゴリ付きリンクと、About下部のリンクでは、紙飛行機に折りたたまれて飛び出してから遷移。通常は約690msで完了します。Escで中止でき、別のリンクを選び直した場合は後の選択を優先します。
- Notesは大きなオリゴリを見出し横へ。狭いスマホでは見出しを全幅にし、説明の隣へ配置します。Aboutは名刺に代わり、大きな触れるオリゴリを中心としたヒーローにしています。
- 制作物・記事・経歴の本文は既存データとコンポーネントを再利用。日英と明暗の設定も既存の操作を引き継ぎます。
- Journalの実行環境はこの静的プレビューに含まれません。入口には公開サイトへのリンクを明示しています。

本番ルートからこのエントリーやCSS・画像は参照されません。出力先はGit管理外の `work/origori-concept/`。今回の作業ではpush・PR・デプロイは行いません。
既存プレビューのページ選択関数を `PreviewPage` として公開し、ローカル案からも共用しています。共通Aboutには任意の`companion`描画枠を追加していますが、本番側は指定しないため従来の名刺を表示します。

## 独立したアイコン素材

- [素材の使い方と一覧](assets/mascots/README.md)
- `assets/mascots/origori-{standing,sitting,idea,resting,plane,face,crumpled}.svg`: 色と折り紙の特徴を引き継いで描き起こした、純粋なベクター素材。画像の埋め込みや背景はありません。
- 同名のPNG: SVGから書き出した長辺1024pxのRGBA画像。背景はアルファ値0、輪郭はアンチエイリアスあり。
- 各素材の余白は約1〜2%。SVGは約0.9〜5.1KBで、任意の大きさに拡大できます。
- ヒーローを含め、サイト内のオリゴリはSVGを使用。CSSによる元画像の切り取り、背景との乗算、円形マスクを廃止しています。

`build-mascots.mjs`が編集用マスターです。変更後に `node dev-pages/origori/build-mascots.mjs` でSVGとPNGを再出力します。紙の細かい質感は省き、小サイズで見分けられる折り面に整理しています。

`assets/origori-reference.png`と初稿の`assets/origori-hero.webp`は参照用に保存していますが、サイトでは読み込みません。内蔵imagegenによる透過再生成はアルファチャンネルのない出力だったため不採用。採用したSVGはコードで描き起こしたものです。[画像生成の試行記録](assets/prompts.md)

## 変形とGIF

`build-motion.mjs`はSVGの面と目・口の線を共通座標のポリゴンに変換します。`motion-geometry.mjs`が面を小さな紙の束へ集め、次の姿にひらきます。CSSの画像切り替えだけではなく、SVGの頂点と色が変化します。変形は480ms、遷移時の折りたたみは340ms。途中のクリックは表示中の面から引き継ぎます。

クリック・Enter・Spaceで操作でき、動きを減らす設定では即時に姿を切り替え、リンクは通常通り遷移します。常時動く装飾はありません。GIFは再生ボタンを押した場合だけ動き、停止でき、同時再生は1つです。

- `origori-fold-and-fly.gif`: 512px角、20fps、52フレーム、2.6秒。
- `origori-crumple-and-unfold.gif`: 512px角、20fps、56フレーム、2.8秒。
- `origori-walking.gif`: 512px角、20fps、32フレーム、1.6秒。横向きの歩行ループ。

いずれも透過背景、無限ループ。GIFの透過は形式上二値で、SVG/PNGのような半透明の輪郭にはなりません。サイト本体は拡大できるSVGを使い、GIFは持ち出し用の素材にしています。

```sh
node dev-pages/origori/build-mascots.mjs
node dev-pages/origori/build-motion.mjs
node dev-pages/origori/build-gifs.mjs
```

`build-motion.mjs`とブラウザ検証にはインストール済みChromeを使用します。外部サイトへの画像送信や新しいパッケージは不要です。

紙飛行機はSVGの中央の折り目から先端への軸を進行方向に合わせて変形し、飛行中は向きを固定して移動します。画面上の出発位置から飛び先への角度を計算し、GIFにも同じ計算を使用しています。回転後の先端が欠けないよう、飛行用の面はキャンバス内に収めています。

## スクロールとおさんぽ

`walking-geometry.mjs`が横向きの歩行用マスターです。4本の手足を分け、接地と振り出しに合わせて関節と折り面を動かします。GIFとサイトの歩行は同じデータを使用。`origori-walking.svg`はその静止ポスターです。

`scroll-companion.tsx`は画面下部の読書進捗に沿ってオリゴリを動かします。下へ進めば右へ、戻れば左を向きます。動作はスクロールイベントを1フレームにまとめ、歩幅は実際の移動量に連動。止まって180ms後に足を220msで揃え、その後は目を休めます。待機中は連続アニメーションを行いません。ページ末尾では星と「さいごまで、ありがとう。」を表示します。

「おやすみ」で姿と位置を固定し、選択は再読み込み後も保持。「また歩く」で復帰します。動きを減らす設定ではおさんぽと専用余白を表示しません。装飾はクリックを遮らず、フッターを隠さないための余白も設けています。テーマや本文の設定は変えません。

## 確認

`verify.mjs`はローカルChromeで以下を確認し、`work/origori-verification/`にスクリーンショットと結果JSONを保存します。

- 幅320 / 390 / 768 / 1024 / 1440px、横はみ出し、見出し、壊れた表示画像。
- 休憩ポーズの往復とレイアウトの高さ維持。
- 日英・明暗切り替え、テーマ保存、動きを減らす設定。
- スマホのメニュー、Escape、フォーカス復帰、ページ移動。
- 制作物・記事・プロフィール・経歴と4件のプロジェクト詳細、記事本文。
- 現行デザインとの切り替え、ブラウザ例外、失敗したリソース。
- 全オリゴリのSVG使用、切り取り・乗算なし、素材一覧のスマホ表示、背景切り替え、SVG/PNGの実ダウンロード。

最終検証: `npm run lint`、TypeScript型検査、`npm run build:origori`、ブラウザ33項目、変形・遷移・GIFの13項目、歩行とスクロールの10項目が通過。7基本素材のSVG・PNG検証は前回通過済み。スクリーンショットは`work/origori-verification/`、動作の詳細は`motion-results.json`と`walking-results.json`に保存しています。

本番ビルドは以前のターンでJournalのpostbuildまで通過し、本番出力にオリゴリの画像や変形データが含まれないことも確認済み。今回の歩行改修はローカルプレビューのみで、本番ビルドは再実行していません。

設定済みChatGPTの独立レビューは、以前から残る未完了の配送記録により未実施です。既存記録の変更や新規送信は行っていません。デザインの採用判断はこのローカル案を見ながら進めます。
